Крок 1

Доступ для збереження

Щоб зберегти зміни, встав GitHub token з правом Contents: Read and write тільки для потрібних репозиторіїв.

Без token можна бачити інтерфейс, але не можна завантажити чи зберегти файл.

Крок 2

Що редагуємо

1 Підключи GitHub token у лівій колонці.
2 Обери субдомен і потрібний розділ.
3 Натисни «Завантажити», зміни поля і збережи.

Почни із завантаження файлу

Після підключення GitHub token натисни «Завантажити». Для текстів і SEO відкриється зручна форма з полями. Технічний код можна переглянути у вкладці «Код».

Це технічний режим. Змінюй код тільки якщо точно розумієш, що редагуєш.
